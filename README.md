# ФИЗИКА-ПОЛИ

Образовательная монополия по физике для 7–11 классов. Макет и рабочий прототип: учитель выбирает класс,
четверть (или весь год), отдельные темы и количество команд — и сразу играет с классом.

![Главный экран](docs/screens/setup.png)

## Что уже работает

**Выбор содержания**
- 5 классов (7–11) с четвертями и темами — **204 темы** по действующему КТП (68 ч на класс), у каждой своя иконка и раздел физики.
- Три режима: «По четвертям» (можно несколько), «Весь год» и «Свои темы» с поиском.
- Мультивыбор классов и готовые пресеты: **Итоги 7–9 классов** (131 тема) и **Итоги 7–11 классов** (204 темы).
- Для каждого класса — свой дизайн поля: палитра рамки, фон, узор (лучи, волны, сетка, молекулы, орбиты, звёзды) и арт центральной панели.

**Игра**
- Поле на 28 клеток с квадратными клетками: 24 содержательные (тема / формула / задача / практика / лаборатория), старт, 2 бонуса и ракета.
- Спокойная яркая палитра: белые карточки клеток с мягким оттенком раздела, бонусы и ракета — в гамме темы класса.
- Кубик со своим дизайном для каждого класса и формата: классический, тепловой, стеклянный, мятный, кристалл и золотой; форма меняется с форматом — скруглённый (четверть), круглый (весь год), сквircle (свои темы) и гранёный (своя монополия).
- Ходы, переход через старт (+100), бонусные карточки, дополнительные броски.
- Вопросы: тесты с вариантами и открытые задания, таймер 60 с, пояснение после ответа.
- Качественные вопросы «почему?» и задания с графиками: график рисуется прямо в окне вопроса.
- Клетка закрепляется за командой; при верном ответе на чужую клетку — перехват (+50).
- Панель учителя: засчитать ответ вручную, пропустить ход, начать заново, завершить игру.
- Хроника ходов, счёт команд, статистика, экран итогов с таблицей и экспортом результатов в CSV.
- **Автосохранение: незавершённая игра сохраняется сама — на экране настройки появится ленточка «Продолжить игру» с составом команд и счётом.**
- **История прохождений: каждая завершённая игра записывается (победитель, очки, статистика команд) — экран «История» в шапке.**
- Звуки (бросок, шаги фишек, верный/неверный ответ, перехват, ракета, круг, финал) — всё можно отключить; анимации кубика, фишек, клеток и итогового подиума. Адаптив под планшет и телефон.

**Свои монополии (конструктор)**
- Создание игры с нуля: название, описание, значок, один из 6 дизайнов поля.
- Свои категории и задания: тест с 2–6 вариантами или открытый ответ, баллы, пояснение.
- Импорт заданий из **CSV** и скачивание шаблона, экспорт своих заданий.
- Демо-монополия «Физика вокруг нас» уже в библиотеке — можно изучить и отредактировать.
- Всё хранится в localStorage браузера (без сервера), дублирование и удаление игр.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка (base = /Monopoly8class/)
npm run preview  # проверка собранной версии
```

Стек: React 18 + TypeScript + Vite, иконки lucide-react, шрифты Unbounded и Rubik (локально).
Бэкенд не нужен — прототип полностью клиентский.

### Публикация

После слияния изменений в `main` GitHub Actions автоматически собирает проект (`npm ci`, `npm run build`)
и публикует содержимое `dist` на GitHub Pages. Настройка находится в
[`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml); в настройках Pages
источником публикации должен быть выбран **GitHub Actions**. При необходимости сборку можно
запустить вручную на вкладке **Actions → Deploy to GitHub Pages → Run workflow**.

## Структура проекта

```
src/
  data/
    programs/       ← КТП по классам: темы, цели обучения, ЛР/ПР, вопросы
      shared.ts     ← типы и хелперы q() / t() / quarter()
      grade7.ts … grade11.ts
      applied.ts    ← практические задания по реальным ситуациям
      index.ts      ← сборка программ
    curriculum.ts   ← производные классы, четверти, темы
    questions.ts    ← банк заданий из программ + проверка целостности
    themes.ts       ← дизайны полей, кубиков, цвета, разделы физики
    storage.ts      ← localStorage, сохранение партии, история, CSV
  game/engine.ts    ← генерация поля, кубик, бонусы, выбор вопросов
  components/       ← экраны: настройка, игра, библиотека, конструктор, история
  styles/           ← оформление по экранам
scripts/            ← headless-проверки (npm run check): навигация,
                      гонка таймеров, автосохранение, история, отображение
```

## Как устроен банк заданий

Содержание больше не демонстрационное: программы классов лежат в `src/data/programs/`, по одному файлу
на класс. У каждой темы есть код цели обучения из КТП, пометка урока (обычный / лабораторная / практика)
и вопросы четырёх типов:

- `theory` — проверка понятий (100 баллов);
- `formula` — формулы и единицы (150);
- `problem` — расчётная задача (200);
- `practice` — реальная ситуация: быт, техника, медицина (250).

`src/data/questions.ts` собирает из программ единый банк, детерминированно перемешивает варианты ответа
(верный вариант не стоит всё время первым) и проверяет целостность через `validateQuestionBank()`.
Кроме четырёх типов вопросов есть теоретические вопросы «на объяснение» и задания с графиками:
`ChartSpec` хранится рядом с вопросом, а компонент `QuestionChart` рисует оси, сетку и линии в SVG.
На каждую тему есть хотя бы одно теоретическое и одно практическое задание. Банк можно пополнять
без кода — через CSV в конструкторе.

## Банк вопросов

763 вопроса по всем классам: 243 теоретических (включая качественные «почему?»), 70 на формулы,
103 расчётные задачи и 347 практических заданий с пояснениями. Из них 44 — с графиками: чтение
графиков движения, нагревания, электрических цепей, колебаний, фотоэффекта и распада.
Этого достаточно для игры по любой четверти и по всему году.
