# ФИЗИКА-ПОЛИ

Образовательная монополия по физике для 7–11 классов. Макет и рабочий прототип: учитель выбирает класс,
четверть (или весь год), отдельные темы и количество команд — и сразу играет с классом.

![Главный экран](docs/screens/setup.png)

## Что уже работает

**Выбор содержания**
- 5 классов (7–11) с четвертями и темами — 95 тем, у каждой своя иконка и раздел физики.
- Три режима: «По четвертям» (можно несколько), «Весь год» и «Свои темы» с поиском.
- Мультивыбор классов и готовые пресеты: **Итоги 7–9 классов** (61 тема) и **Итоги 7–11 классов** (95 тем).
- Для каждого класса — свой дизайн поля: палитра рамки, фон, узор и арт центральной панели.

**Игра**
- Поле на 28 клеток: 24 содержательные (тема / формула / задача / лаборатория), старт, 2 бонуса и ракета.
- Кубик, ходы, переход через старт (+100), бонусные карточки, дополнительные броски.
- Вопросы: тесты с вариантами и открытые задания, таймер 60 с, пояснение после ответа.
- Клетка закрепляется за командой; при верном ответе на чужую клетку — перехват (+50).
- Панель учителя: засчитать ответ вручную, пропустить ход, начать заново, завершить игру.
- Хроника ходов, счёт команд, статистика, экран итогов с таблицей и экспортом результатов в CSV.
- Звуки (можно отключить), адаптив под планшет и телефон.

**Свои монополии (конструктор)**
- Создание игры с нуля: название, описание, значок, один из 6 дизайнов поля.
- Свои категории и задания: тест с 2–6 вариантами или открытый ответ, баллы, пояснение.
- Импорт заданий из **CSV** и скачивание шаблона, экспорт своих заданий.
- Демо-монополия «Физика вокруг нас» уже в библиотеке — можно изучить и отредактировать.
- Всё хранится в localStorage браузера (без сервера), дублирование и удаление игр.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка
npm run preview
```

Стек: React 18 + TypeScript + Vite, иконки lucide-react, шрифты Unbounded и Rubik (локально).
Бэкенд не нужен — прототип полностью клиентский.

## Структура проекта

```
src/
  data/
    curriculum.ts   ← классы, четверти, темы (сюда встанут КТП)
    questions.ts    ← демо-банк вопросов (сюда встанут учебники)
    themes.ts       ← дизайны полей, цвета, разделы физики
    storage.ts      ← localStorage, CSV-импорт/экспорт, демо-монополия
  game/engine.ts    ← генерация поля, кубик, бонусы, выбор вопросов
  components/       ← экраны: настройка, игра, библиотека, конструктор
  styles/           ← оформление по экранам
```

## Что подготовлено к следующему шагу

Макет специально разделён так, чтобы материалы учебников и КТП подставлялись без переделки интерфейса:

1. **КТП → `src/data/curriculum.ts`.** Каждая четверть — массив тем `[название, короткое имя, раздел, иконка]`.
   Достаточно заменить содержимое `quarter(...)` реальными пунктами программы — выбор тем, пресеты и поле
   обновятся автоматически.
2. **Учебники → `src/data/questions.ts`.** Вопросы привязаны к `topicId` (например `g8-q3-t4` — «Закон Ома»),
   типу (`theory | formula | problem`) и баллам. Движок сам подбирает вопрос под тип клетки.
   Банк можно пополнять и без кода — через CSV в конструкторе.
3. **Новые классы/предметы.** Тип `GradeId` и `THEMES` расширяются, если появятся, например, 8-й класс
   с другой программой или углублённый уровень.

## Демо-банк

194 вопроса по всем классам: теория, формулы и расчётные задачи с пояснениями. Этого достаточно для
игры по любой четверти; при загрузке учебников банк расширим по каждой теме.
